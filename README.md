# AWS Certified Solutions Architect – Associate

This repository contains my notes, hands-on labs, AWS CLI examples, and Infrastructure as Code while studying for the AWS Certified Solutions Architect – Associate (SAA-C03) certification.

The goal isn't just to complete the certification—it's to understand how AWS services work, document what I learn, and build practical cloud engineering experience along the way.

## Repository Structure

* **00-Setup** – AWS account, IAM, AWS CLI, budgets
* **01-Storage** – S3, EBS, EFS, FSx
* **02-Compute** – EC2, Lambda, ECS, EKS
* **03-Identity-and-Security** – IAM, Cognito, KMS, Secrets Manager
* **04-Networking** – VPC, Route 53, CloudFront
* **05-Databases** – RDS, Aurora, DynamoDB, Redshift
* **06-Monitoring** – CloudWatch, CloudTrail
* **07-Infrastructure-as-Code** – CloudFormation

I'll keep updating this repository as I progress through the course.
